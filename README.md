# AI Chatbot

A production-ready Flutter application that integrates Google Gemini through [`flutter_gemini`](https://pub.dev/packages/flutter_gemini) to deliver a conversational AI experience on mobile and desktop. The chatbot streams multimodal responses, supports image prompts, and presents the conversation using an intuitive chat interface built with [`dash_chat_2`](https://pub.dev/packages/dash_chat_2).

## Features

- **Streaming responses** — Uses Gemini's streaming API to display partial answers in real time as the model generates them.
- **Multimodal prompts** — Accepts gallery images and sends them alongside user prompts for richer responses.
- **Modern chat UI** — Leverages `dash_chat_2` for avatars, typing bubbles, media previews, and message history.
- **Cross-platform Flutter** — Runs on Android, iOS, web, Windows, macOS, and Linux with a single codebase.

## Tech Stack

- **Framework**: Flutter (`sdk: flutter`)
- **AI Integration**: `flutter_gemini ^2.0.5`
- **Chat Interface**: `dash_chat_2 ^0.0.21`
- **Media Capture**: `image_picker ^1.1.2`

All dependencies are declared in `pubspec.yaml`.

## Getting Started

### Prerequisites

1. Flutter SDK 3.5.1 or newer installed and added to your PATH.
2. A Google Gemini API key with access to the desired Gemini models.
3. Xcode / Android Studio toolchains if you plan to build for iOS or Android.

### Installation

1. Clone the repository.
2. Open a terminal at the project root and install dependencies:
   ```sh
   flutter pub get
   ```
3. Configure your Gemini API key as described below.

## Configuration

This project reads the Gemini API key from `lib/consts.dart` as the `GEMINI_API_KEY` constant.

1. Create a safe copy of your API key.
2. Update `lib/consts.dart`:
   ```dart
   const String GEMINI_API_KEY = 'YOUR_REAL_GEMINI_API_KEY';
   ```
3. **Do not** check your real key into version control. Consider using environment-specific files or injecting the key at build time via `--dart-define` for production builds.

## Running the App

Launch on an emulator, simulator, or connected device:

```sh
flutter run
```

To target a specific platform:

```sh
flutter run -d android
flutter run -d ios
flutter run -d chrome
```

## Project Structure

````
lib/
├── consts.dart        # Stores configuration such as the Gemini API key placeholder
├── home_page.dart     # Stateful chat UI and Gemini streaming logic
└── main.dart          # App entry point and Gemini initialization
```

Additional Flutter platform folders (`android/`, `ios/`, `web/`, `windows/`, etc.) are generated by Flutter and contain platform-specific build files.

## Troubleshooting

- **Missing API key**: Ensure `GEMINI_API_KEY` in `lib/consts.dart` is populated with a valid key.
- **Permission issues on mobile**: Confirm the appropriate runtime permissions are granted when picking images.
- **Streaming stops unexpectedly**: Check network connectivity and verify your Gemini quota and model availability.
